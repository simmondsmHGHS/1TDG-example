This is an exemplar website for 1TDG's AS92005 website.

The purpose of this website is to develop a website for the (fake) Warhammer Club at HGHS.

Students who are a part of the club need a website to easily find club information, as well as a place to find the Ruleset, and be inspired by other member's creations.

Students who are interested, but not quite sure if they want to join the club can see what it's all about.
